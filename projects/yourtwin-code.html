YOURTWIN: CODE

AI-powered coding education platform using digital twin technology to deliver personalized programming instruction, real-time code execution, and adaptive learning through behavioral analytics.

Problem

Traditional coding education platforms provide static content and generic feedback, failing to adapt to individual learning behaviors and skill progression. Students often struggle with inefficient study patterns, lack of personalized guidance, and delayed feedback during coding practice. Instructors also lack real-time visibility into student performance and engagement. This project addresses these gaps by introducing an AI-powered digital twin system that models each learner's behavior and delivers adaptive, real-time support.

Features Overview

Interactive Code Environment
Monaco-powered editor with multi-language support and real-time execution via Judge0 API.
Shadow Twin AI Assistant
5-level progressive hint system that adapts to student performance using scaffolding techniques.
Digital Twin Analytics
Tracks behavior (typing speed, errors, pauses) to model competency and learning patterns.
Real-time Monitoring
Live activity tracking for instructors with WebSocket-based updates and dashboards.
Academic Integrity System
Plagiarism detection, behavior monitoring, and AI restriction during assessments.
Personality-Adaptive AI
Multiple AI personas (Mentor, Coach, Socratic, etc.) tailored to different learning styles.

How It Works

User Interaction

Students write and execute code through a web-based editor and terminal.

Behavior Tracking

The system continuously collects behavioral data (typing patterns, errors, timing).

Digital Twin Modeling

A "Mirror Twin" builds a behavioral profile, while a "Shadow Twin" generates adaptive guidance.

AI Processing

Multiple LLMs and ML models analyze performance, predict outcomes, and optimize learning paths.

Real-time Feedback

Students receive instant hints, corrections, and recommendations, while instructors monitor progress live.
