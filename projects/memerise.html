MemeRise

AI-powered mnemonic generation combined with meme templates creates a dual-sensory learning experience that makes memorization engaging and effective.

Live Demo → View on GitHub →

Problem

Students often struggle to memorize lists and structured information such as scientific processes, historical sequences, or categorized concepts. Traditional mnemonic techniques require manual creativity and often lack visual reinforcement, making them less engaging and harder to retain. Most learning tools fail to combine humor and imagery — two key factors that improve memory recall.

Features Overview

AI Mnemonic Generator
Automatically generates memorable and humorous mnemonics from user-provided lists using AI.
Meme Template Library
30+ templates including global classics and Filipino meme formats for cultural relevance.
AI Image Generation
Generates custom visuals using AI when predefined templates are not used.
Custom Meme Creator
Drag-and-drop editor with text overlay and export functionality for personalized memes.
Instant Export
Download generated memes as PNG directly in the browser — no backend required.

Tech Stack

Frontend

HTML5, Vanilla JavaScript (ES6+), Tailwind CSS

APIs

Google Gemini API (mnemonic generation), Pollinations AI (image generation)

Core Technology

HTML5 Canvas API (rendering and export)

Architecture

Fully client-side application with external API integration

How It Works

Input

User inputs a topic and a list of items to memorize.

AI Generation

The application sends the input to the Gemini API, which generates a mnemonic sentence based on the list.

Template Selection

User selects a meme template or generates a custom image.

Canvas Rendering

Canvas API renders the mnemonic onto the image with optimized text placement.

Export

Final meme is exported as a downloadable PNG.

Future Improvements

  • Integrate adaptive AI to personalize mnemonic style based on user preference
  • Add spaced repetition system for long-term retention tracking
  • Expand template library with user-generated meme uploads
  • Enable cloud saving and sharing of generated memes
  • Optimize prompt engineering for higher-quality mnemonic outputs
