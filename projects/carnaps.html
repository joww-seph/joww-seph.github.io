carNaps

A sensor-based autonomous search and rescue robotic system. Designed to detect obstacles and collect objects using multi-sensor input and a motorized claw mechanism for search and rescue, autonomous delivery, and object retrieval in constrained environments.

Problem

Search and rescue environments are often unpredictable, requiring systems that can navigate autonomously while detecting and interacting with objects. Many low-cost robotic platforms lack the ability to combine real-time obstacle detection with object manipulation in a single system, limiting their usefulness in real-world scenarios such as debris navigation or item retrieval. carNaps was built to address this by integrating multi-sensor perception with autonomous movement and a functional robotic claw.

Features Overview

Multi-Sensor Obstacle Detection
Uses three ultrasonic sensors for front and lateral distance measurement, combined with IR sensors for diagonal proximity detection.
Autonomous Navigation
Implements real-time obstacle avoidance and path adjustment without human intervention.
Robotic Claw Manipulation
Servo-driven claw capable of grasping and collecting objects during operation.
Efficient Motor Control
L298 motor driver enables independent control of four DC motors for precise movement.
Integrated Sensor Processing
All sensor data is processed on-board, allowing coordinated decision-making in real time.

How It Works

Environment Sensing

Ultrasonic sensors continuously measure distances ahead and to the sides, while IR sensors detect diagonal proximity and nearby objects.

Sensor Fusion & Decision Logic

The Arduino processes incoming sensor data simultaneously, determining whether to move forward, turn, or stop based on obstacle thresholds.

Autonomous Navigation

Motor outputs are adjusted in real time via the L298 driver, allowing the robot to dynamically avoid obstacles.

Object Interaction

When an object is detected within range, the servo-driven claw is activated to grasp and collect it.
