Automata — AI Classroom Orchestration System

An AI-powered classroom orchestration system that automates the entire teaching session lifecycle — from attendance to assessment — using computer vision, real-time systems, and generative AI.

Problem

Traditional classroom management is fragmented and time-consuming. Teachers manually handle attendance, prepare lecture materials, conduct recitations, and create assessments — often using separate tools. This leads to inefficiencies, inconsistent workflows, and reduced time for actual teaching. Additionally, most systems lack real-time responsiveness and personalization.

Features Overview

AI Attendance System
Automatically detects and marks students present using real-time face recognition via webcam.
AI Lecture Generation
Converts a single uploaded file into structured slides, narration, and visual content using Gemini AI.
Smart Hand Raise Detection
Detects physical hand raises using pose estimation and identifies the student via facial recognition.
AI-Powered Recitation
Transcribes spoken answers and evaluates them instantly with AI-generated feedback.
Automated Quiz System
Generates, deploys, and auto-grades quizzes with real-time leaderboard updates.
Live Teacher Dashboard
Real-time updates via WebSockets for attendance, participation, and quiz progress.

How It Works

Automata operates as a state-driven orchestration system that automates classroom flow.

Input Phase

Teacher uploads lecture material — backend triggers AI pipeline.

AI Processing Pipeline

Generates slides, narration, questions, and quizzes using Gemini. Pre-caches audio using TTS services. Stores structured data in the database.

Live Session Execution

Attendance via face recognition. Lecture delivery with synced slides and audio. Hand raises detected via pose and identity matching. Recitation answers evaluated in real time.

Assessment Phase

Quiz is deployed and auto-graded instantly. Results streamed live to teacher dashboard.

Output Phase

All session data compiled into a downloadable report.

The system is powered by a Laravel-based orchestration layer with async queue, coordinating multiple AI services without manual intervention.
